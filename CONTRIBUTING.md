# Contributing to Trackpad Free

Thanks for helping! Bug reports, testing on other trackpad models, and pull
requests are all welcome.

## Ground rules

- **Standard library only.** Trackpad Free must run on a stock Python
  install, so no pip dependencies. Windows APIs are called through `ctypes`
  with explicit `argtypes`/`restype` and `use_last_error=True` (see `tray.py`).
- **Never block the UI.** Slow work (PowerShell, driver requests, downloads)
  runs on a worker thread or in a bounded subprocess; see `TrackpadApp._work`.
- **Be honest in the UI.** Only claim what was verified (for example "Paired"
  vs. "Connected").
- **License.** Contributions are accepted under GPL-2.0-or-later. Do not copy
  code from projects with incompatible licenses; credit any borrowed design in
  `THIRD_PARTY.md`.

## Development setup

```
git clone <your fork>
cd MagicTrackpadFree
python app.py
```

Run the tests (hardware-free, also run by CI on Windows):

```
python -m unittest discover -s tests
```

## UI conventions

The window is plain Tk/ttk styled by `ui.py`:

- Build pages from stock ttk widgets; `ui.Theme` styles `TLabel`,
  `TCheckbutton`, `TRadiobutton`, `TLabelframe`, `TButton`, `TCombobox` and
  friends, so they match light and dark mode automatically.
- Group related controls in `ui.Card(page, title=..., subtitle=...)`.
- Use `ui.WrapLabel` (packed with `fill="x"`) for text that should wrap.
- Styles: `Accent.TButton` for the one main action on a page, `Link.TButton`
  for low-emphasis actions, `Muted.TLabel` / `Small.TLabel` for secondary text,
  and `ui.set_pill(label, "good" | "warn" | "bad" | "neutral", text)` for status.
- Sizes are 96-DPI design pixels; wrap them in `ui.px()`.
- Add a page with `self.tabs.add(frame, text="Name", subtitle="...")`, the same
  API as `ttk.Notebook`. Add an icon for it in `ui.NAV_ICONS`.

After a visible UI change, refresh the README screenshots (demo data, no real
device identifiers):

```
python tools/screenshot.py --theme light
python tools/screenshot.py --theme dark
```

The app icon is generated by `python tools/make_icons.py`.

## Releasing

1. Update `version.py` and add the release to `CHANGELOG.md`.
2. Commit, then tag and push: `git tag v0.3.0 && git push origin v0.3.0`.
3. The **Release** workflow runs the tests, checks the tag matches
   `version.py`, and publishes `TrackpadFree-v0.3.0.zip` (source without
   tests, tools and docs) to GitHub Releases.
