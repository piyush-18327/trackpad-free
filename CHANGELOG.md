# Changelog

All notable changes to Trackpad Free. Versions follow `version.py`; release
tags are `v<version>`.

## [0.4.0] – 2026-10-21

### Added
- Appearance picker in the sidebar: Light, Dark or Match Windows. It applies
  instantly, follows Windows live in Match Windows mode, and is remembered in
  `%APPDATA%\TrackpadFree\app.json`.
- Opt-in five-finger double-tap gesture that opens Windows' screenshot
  overlay (Win+Shift+S). See `docs/gestures.md`.

### Fixed
- Closing the window before its pending idle work had run could fail with
  "can't delete Tcl command".

## [0.3.0] – 2026-10-21

First public release.

### Added
- Driver setup: pinned, SHA-256-verified download of the Microsoft-signed
  MagicTrackpad2ForWindows v2.2 package with its GPL source, and an elevated
  installer that re-checks the Microsoft signature.
- Click strength, silent clicking, palm and hover rejection settings.
- Battery reading over Bluetooth and a diagnostics view.
- Notification-area tray icon with the battery percentage and low-battery
  alerts at 20% and 10%, started at sign-in by an elevated scheduled task
  after a one-time setup.
- Windows 11-style window: sidebar navigation, card layout, battery gauge,
  status pills, light and dark mode that follow Windows, a matching title bar,
  and crisp text on high-DPI displays.
- App icon (`assets/`), generated by `tools/make_icons.py`.
- Mac preset for Windows' own touchpad gestures, applied and restored as one
  read-back-verified transaction.
- Opt-in Mac gestures run by the tray: three-finger drag, smart zoom
  (per window), Notification Center edge swipe, Launchpad pinch and Look up.
  Look up reads the word under the pointer through UI Automation, so it never
  clicks, types or touches the clipboard. See `docs/gestures.md`.
- GitHub project files: CI on Python 3.10–3.13, tagged release packaging,
  issue and pull request templates, contributing and security guides.
